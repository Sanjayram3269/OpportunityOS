# OpportunityOS

AI-powered opportunity discovery and outreach CRM.

## Vision

OpportunityOS helps manage the full opportunity outreach workflow:

`Discover → Qualify → Personalize → Approve → Send → Track → Follow up → Analyze`

The system is designed around human approval for outbound communication, with automation focused on research, scoring, drafting, tracking, and analytics.

## Repository

- Owner: `Sanjayram3269`
- Default branch: `main`

## Planned stack

- Web: Next.js + TypeScript + Tailwind CSS
- API: FastAPI + Python
- Database: PostgreSQL
- AI: LLM-based structured workflows
- Exports: CSV / XLSX

## Development principle

Build in small, tested vertical slices. Every feature should be implemented, verified, and committed before moving to the next one.
